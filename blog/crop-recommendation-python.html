Building a Crop Recommendation System with Python

The Problem

Agriculture remains one of the largest employers worldwide, yet many farmers still rely on intuition and experience to decide which crops to plant. Soil composition varies dramatically across regions, and planting the wrong crop in the wrong soil can lead to poor yields, wasted resources, and financial loss.

A crop recommendation system takes the guesswork out of this decision. By analyzing soil parameters — nitrogen, phosphorus, potassium levels, temperature, humidity, pH, and rainfall — a machine learning model can predict which crop is most likely to thrive in a given environment.

The Dataset

The Crop Recommendation dataset contains 2,200 samples across 22 different crops. Each sample includes seven numerical features:

  • N — Nitrogen content in the soil (kg/ha)
  • P — Phosphorus content in the soil (kg/ha)
  • K — Potassium content in the soil (kg/ha)
  • Temperature — Average temperature in Celsius
  • Humidity — Relative humidity percentage
  • pH — Soil pH value
  • Rainfall — Rainfall in mm

The target variable is the crop label — one of 22 crops including rice, wheat, maize, cotton, coffee, mango, and more.

Data Exploration

Before building the model, it's worth understanding the data. Load the dataset and check basic statistics: 

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv('Crop_recommendation.csv')
print(df.shape)       # (2200, 8)
print(df.head())
print(df.describe())
print(df['label'].value_counts())

The dataset is balanced — each crop has exactly 100 samples. This means we don't need to worry about class imbalance during training.

Correlation analysis reveals which features matter most. Temperature and humidity tend to be highly correlated, as do nitrogen and phosphorus levels in certain soil types.

Feature Engineering

The raw features are sufficient for a baseline model, but a few transformations can improve performance: 

from sklearn.preprocessing import LabelEncoder, StandardScaler

# Encode the target labels
le = LabelEncoder()
df['label_encoded'] = le.fit_transform(df['label'])

# Separate features and target
X = df.drop(['label', 'label_encoded'], axis=1)
y = df['label_encoded']

# Scale features (important for some algorithms)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

Standard scaling ensures that features like rainfall (which ranges from 20-300mm) don't dominate features like pH (which ranges from 3.5-9.5) simply because of their magnitude.

Model Training

Random Forest is an excellent choice for this problem. It handles multi-class classification well, requires minimal hyperparameter tuning, and provides feature importance rankings. For a detailed comparison of tree-based algorithms, see my article on Decision Tree vs Random Forest. 

from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split, cross_val_score

X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.2, random_state=42, stratify=y
)

# Train the model
rf_model = RandomForestClassifier(
    n_estimators=200,
    max_depth=20,
    min_samples_split=5,
    random_state=42
)
rf_model.fit(X_train, y_train)

# Evaluate with cross-validation
cv_scores = cross_val_score(rf_model, X_scaled, y, cv=5, scoring='accuracy')
print(f"Cross-validation accuracy: {cv_scores.mean():.4f} (+/- {cv_scores.std():.4f})")

With proper tuning, Random Forest typically achieves 95-99% accuracy on this dataset. The model learns distinct soil profiles for each crop — rice thrives in high-humidity, high-rainfall environments, while cotton prefers warmer, drier conditions.

Evaluation

Beyond overall accuracy, a confusion matrix reveals which crops are最容易 confused: 

from sklearn.metrics import classification_report, confusion_matrix

y_pred = rf_model.predict(X_test)
print(classification_report(y_test, y_pred, target_names=le.classes_))

Most crops achieve near-perfect precision and recall. The few misclassifications typically occur between botanically similar crops (e.g., moong vs. masoor beans) that share similar soil requirements.

Feature Importance

One of Random Forest's strengths is built-in feature importance. Understanding which features drive predictions adds interpretability: 

importances = rf_model.feature_importances_
feature_names = X.columns

# Sort by importance
indices = np.argsort(importances)[::-1]
for i in indices:
    print(f"{feature_names[i]}: {importances[i]:.4f}")

Typically, rainfall, humidity, and temperature are the most important features for crop selection, followed by potassium and nitrogen levels. This aligns with agricultural science — climate and soil nutrients are the primary determinants of crop suitability.

Deployment with Streamlit

A trained model is only useful if people can interact with it. Streamlit turns the Python script into a web application with minimal effort. For a comprehensive guide on ML deployment with Streamlit, see my Streamlit deployment article. 

import streamlit as st
import joblib

# Load model and scaler
model = joblib.load('crop_model.pkl')
scaler = joblib.load('scaler.pkl')
le = joblib.load('label_encoder.pkl')

st.title("Crop Recommendation System")

# Input fields
n = st.slider("Nitrogen (N)", 0, 150, 50)
p = st.slider("Phosphorus (P)", 0, 150, 50)
k = st.slider("Potassium (K)", 0, 200, 50)
temperature = st.slider("Temperature (°C)", 0.0, 50.0, 25.0)
humidity = st.slider("Humidity (%)", 0.0, 100.0, 70.0)
ph = st.slider("Soil pH", 0.0, 14.0, 6.5)
rainfall = st.slider("Rainfall (mm)", 0.0, 400.0, 100.0)

if st.button("Recommend Crop"):
    features = np.array([[n, p, k, temperature, humidity, ph, rainfall]])
    features_scaled = scaler.transform(features)
    prediction = model.predict(features_scaled)
    crop_name = le.inverse_transform(prediction)[0]
    st.success(f"Recommended crop: {crop_name}")

Extensions and Improvements

This baseline system can be extended in several directions:

  • Multi-crop recommendations — Return top-3 crops with confidence scores instead of a single prediction
  • Seasonal filtering — Incorporate planting season as an additional feature
  • Regional data — Train on region-specific soil data for more accurate local recommendations
  • Fertilizer suggestions — Extend the system to recommend fertilizers alongside crops
  • API deployment — Wrap the model in a FastAPI service for integration with mobile apps

Conclusion

Building a crop recommendation system demonstrates the full ML pipeline: data exploration, preprocessing, model training, evaluation, and deployment. Random Forest provides a strong baseline with minimal tuning, and Streamlit makes deployment accessible without frontend expertise. The real value emerges when farmers and agricultural advisors can use such tools to make data-driven planting decisions.
